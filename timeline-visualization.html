Timeline[T]

A step function over time: one value of type T at every instant, changing only at segment boundaries. Backed by a pandas DataFrame with start, end, value columns.

The data structure

Timeline.from_segments([(start, end, value), …])

Segments are validated on construction — violations raise ValueError / TypeError, never assertions.

  • Contiguous — segment[i].end == segment[i+1].start: no gaps, no overlaps.
  • Sorted — start times are monotonically increasing.
  • Half-open — each segment covers [start, end); start < end always.
  • Total — exactly one value is defined for any point within the duration.
  • Immutable — every operation returns a new Timeline; .df exposes only a copy.
